# SMOKE

A responsive, free browser gaming hub built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. After GitHub finishes deploying, the site should be available at `https://jebediahkerman1.github.io/Smoke/`.

## Logo
The exact supplied SMOKE logo artwork is stored as `logo.webp` and used in the main header and site icon. The site is a parody demo offering free browser games; no purchases or game downloads are required.


## Games
- [SMOKE Portal](https://jebediahkerman1.github.io/Smoke/portal.html) — first-person portal puzzle prototype.
- [SMOKEBLOCKS](https://jebediahkerman1.github.io/Smoke/craft.html) — block sandbox with grass, trees, water, wood, stone, mining, building, crafting and local world saves.

SMOKE games are free browser experiences. SMOKEBLOCKS is an original block-building sandbox parody and is not affiliated with Mojang or Microsoft.


## New 3D browser games
- [Counter Smoke](https://jebediahkerman1.github.io/Smoke/strike.html) — original round-based tactical 3D shooter vs bots.
- [Payload Panic](https://jebediahkerman1.github.io/Smoke/payload.html) — original class-based payload shooter with Scout, Soldier, Heavy, and Medic roles.
- [Zombie Shift](https://jebediahkerman1.github.io/Smoke/zombie.html) — original low-poly 3D horde-survival shooter.

These are original parody-inspired browser games, not affiliated with Counter-Strike, Team Fortress 2, or other third-party franchises. The pages use the Three.js library from a CDN and need an internet connection to load the 3D engine.


SMOKEBLOCKS keeps the earlier local save data when upgrading from the previous SMOKECRAFT build and migrates it to the new save key.
